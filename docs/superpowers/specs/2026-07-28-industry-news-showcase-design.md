# 行业动态专题展示页设计

## 目标

将“行业动态”从博客标签跳转页改为专题入口页。它不显示既有 news 或页面介绍，只展示由站点维护的专题内容；最新专题置顶，其余专题在响应式网格中按发布日期倒序排列。

## 页面与内容结构

- `/industry-news` 使用 Docusaurus 的 `Layout`，因此网站顶部导航、页脚和全局主题保持可见。
- 专题清单由页面内的元数据数组维护，按发布日期降序排序。首项以跨列的主卡片展示，后续项在宽屏为两至三列、窄屏为单列。
- 初始清单只包含“比亚迪战略全景｜从电池厂到全球科技帝国的「四化」征途”。现有博客标签页不再作为该栏目内容源。
- 每个卡片直接链接到专题的稳定 URL，专题页不放在 news 子目录。

## 专题页

- 将用户提供的完整 HTML 保存为静态专题页，保留文章自身的排版、动画、折叠内容、标签页和章节二级导航。
- 站点顶部导航继续显示。为避免双层粘性导航相互遮挡，源文件的页内导航放在站点导航下方，并根据实际站点导航高度设置顶部偏移。
- 专题页面样式使用局部作用域，避免覆盖站点全局样式；移动端保持源文件的自适应布局。

## 错误处理与兼容性

- 清单没有内容时显示简洁空状态，不显示旧 news。
- 仅使用本地静态资源与原生浏览器能力，不引入第三方运行时依赖。
- 使用 Docusaurus 生产构建验证路由、链接与静态文件可访问性。

## 验收标准

1. `/industry-news` 不再跳转至博客标签页，也没有栏目介绍或旧新闻。
2. 首屏只有一个比亚迪专题主卡，点击进入专题页。
3. 专题页与行业动态页都显示网站顶部导航；源页面内的章节导航仍可用。
4. 在手机、平板和桌面宽度下，卡片网格和专题内容均可正常浏览。
5. `npm run build` 成功完成。
